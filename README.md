# 네이버 블로그 글쓰기 자동화

키워드 2~3개와 제목을 넣으면 SEO 글을 쓰고, 무료 이미지를 찾아 정사각형·고화질로 다듬은 뒤,
크롬 브라우저를 띄워 네이버 블로그 에디터에 **키보드로 직접 입력하고 임시저장**까지 진행하는 Electron 프로그램입니다.

## 1. 처음 한 번만 하는 준비

1. Node.js LTS 설치 (https://nodejs.org)
2. `글쓰기.bat` 실행 → 처음 실행이면 필요한 프로그램을 자동으로 설치합니다.
3. 브라우저가 열리고 네이버 로그인 화면이 나오면 **직접 한 번 로그인**합니다.
   로그인 정보는 `data\naver-profile` 폴더에 남아 다음부터는 자동으로 들어갑니다.

## 2. 사용 방법

### 방법 A. bat 파일로 실행 (글마다 키워드와 제목을 묻습니다)

```
글쓰기.bat
  글 1 키워드 (비우면 끝) : 리눅스마스터 2급, 리눅스마스터 시험일정
  글 1 제목   (비우면 자동) : 리눅스마스터 2급, 하루 2시간 기출만 돌렸더니 결국 붙더라
  글 2 키워드 (비우면 끝) :
  바로 글을 쓰고 임시저장까지 진행할까요? [Y / N]
```

- 글은 한 번에 **최대 20개**까지 넣을 수 있습니다. 20번째까지 묻고, 키워드를 비우고 Enter 를 누르면 그 자리에서 입력을 마칩니다.
- 제목을 넣으면 **그 제목 그대로** 쓰고, 글도 그 제목이 묻는 것에 맞춰 씁니다.
- 제목을 비워 두면 **키워드를 조합해 제목을 자동으로** 만듭니다(AI 후보 중 가장 나은 1개).
- 제목에 `&`, `%`, `!`, 괄호 같은 기호를 써도 됩니다. 큰따옴표(")만 작은따옴표(')로 바뀝니다.
- `Y` 를 누르면 글 작성 → 이미지 → 네이버 입력 → 임시저장까지 한 번에 진행합니다.

### 방법 B. 프로그램 화면에서 실행

`npm start` 또는 bat 에서 `N` 을 누르면 화면이 뜹니다.

- **키워드를 묶어서 글 1개** : 키워드 3개를 하나의 글에 녹여 씁니다.
- **키워드별로 각각 글 작성** : 키워드마다 글을 따로 쓰고, 한 편씩 이어서 임시저장합니다.
- **키보드 입력 방식** : 요청하신 키스트로크 방식입니다. 글자를 하나씩 입력합니다.
- **빠른 입력** : 서식이 담긴 내용을 Ctrl+V 로 붙입니다. 색과 글자 크기가 더 정확하게 들어갑니다.

## 3. 만들어지는 글의 구성

| 순서 | 내용 |
| --- | --- |
| 이미지 | 서론 위 대표 이미지 1장 |
| 서론 | 공감 문제 제기 + 이 글에서 얻는 것 + 핵심 강조 문장(주황색) |
| 본론 | 소제목 5개 이상, 소제목마다 **이미지 1장** + 문단 3개 + 강조 문장 |
| 결론 | 요약 + 강조 문장 + 댓글 유도 질문(파란색) |
| 이미지 | 결론 밑 마무리 이미지 1장 |
| 전체 글 목록 | 4개 |
| 육박사의 간단 요약 | 4줄 |
| 태그 | 10개 한 줄 |

- 소제목은 **연관 검색어의 의도별로** 만들어집니다. (시점 / 방법 / 비용 / 준비물 / 기준·자격 / 장소 / 증상·원인 / 비교·추천 / 기타 9가지)
- 소제목 사이에 가는 구분선이 들어가 읽기 편합니다.
- 사진은 **주제어를 영어로 바꿔 검색**합니다. (아기 → baby hands, 제과기능사 → cooking kitchen, 전기기능사 → tools workshop)
- 사진이 어두우면 **밝기를 자동으로 올립니다.**
- 본문 글자 크기는 **15픽셀**, 소제목은 19픽셀 굵게 네이비입니다.
- 중요 문장은 **주황색 굵게**, 질문 문장은 파란색으로 들어갑니다.
- 모든 문장은 `합니다 / 습니다 / 입니다` 로 끝납니다. 해요체는 자동으로 바꿉니다.
- 키워드 뒤 조사(을/를, 은/는, 이/가)를 받침에 맞게 자동으로 고칩니다.
- 공백 제외 1500자 이상이 되도록 모자라면 내용을 더 채웁니다.

## 4. 글쓰기 엔진 3가지 (API 키 없이도 됩니다)

프로그램 화면의 **글쓰기 엔진**에서 고릅니다. 기본값인 `자동` 은 Gemini 키 → 로컬 AI → 내장 글 틀 순서로 알아서 씁니다.

| 엔진 | API 키 | 설치 | 속도 | 설명 |
| --- | --- | --- | --- | --- |
| **내장 글 틀** | 필요 없음 | 없음 | 즉시 | 연관 검색어가 **무엇을 묻는지 9가지로 구분**해 그에 맞는 내용을 씁니다. 시점을 물으면 기간 확인법을, 비용을 물으면 금액 따지는 법을, 준비물을 물으면 고르는 기준을 씁니다. |
| **로컬 AI (Ollama)** | **필요 없음** | 약 3GB | 1~5분 | 내 컴퓨터에서 도는 무료 AI 입니다. 가입도 인터넷도 필요 없습니다. |
| Gemini | 무료 키 발급 | 없음 | 20~60초 | 품질이 가장 좋습니다. |

### 로컬 AI(Ollama) 설치 — 키 없이 AI 쓰는 방법

1. 프로그램의 **로컬 AI 설치** 버튼을 누르면 https://ollama.com/download 가 열립니다. 설치합니다.
2. 명령 프롬프트에서 한 번만 실행합니다.
   ```
   ollama pull gemma3:4b
   ```
3. 프로그램을 다시 켜면 위쪽에 `로컬 AI(gemma3:4b) 연결` 이 뜹니다. 이제 키 없이 AI 가 글을 씁니다.

- 다른 모델을 쓰려면 `.env` 의 `OLLAMA_MODEL` 을 바꿉니다. (`qwen3:4b`, `gemma3:12b` 등)
- 전용 그래픽카드가 없는 컴퓨터에서는 `4b` 급이 적당합니다. `12b` 이상은 많이 느려집니다.
- 추천하지 않는 방법: ChatGPT 나 Gemini **웹사이트를 브라우저로 자동 조작**하는 방식입니다. 기술적으로는 가능하지만 해당 서비스 약관이 자동화 접근을 막고 있어 계정 제재 위험이 있습니다.

## 5. 무료 API 안내 (키가 없어도 동작합니다)

`API 키 설정(.env)` 버튼을 누르면 `.env` 파일이 열립니다. 필요한 것만 채우면 됩니다.

| 용도 | 서비스 | 무료 한도 | 발급 주소 |
| --- | --- | --- | --- |
| 글 작성 AI | **Google Gemini** (추천) | 무료 등급 제공, 신용카드 없이 발급 | https://aistudio.google.com/apikey |
| 글 작성 AI | **Ollama (로컬)** | **키 없이 무제한** | https://ollama.com/download |
| 이미지 | **Pixabay** (추천) | 무료, 한국어 검색 지원, 출처 표기 불필요 | https://pixabay.com/api/docs/ |
| 이미지 | Pexels | 월 20,000건 무료 | https://www.pexels.com/api/ |
| 이미지 | Unsplash | 시간당 50건 무료 | https://unsplash.com/developers |
| 이미지 | **Openverse** | **키 없이 사용** (CC 라이선스) | 자동으로 사용합니다 |
| 이미지 | **Picsum** | **키 없이 사용** (마지막 대비용) | 자동으로 사용합니다 |
| 소재 조사 | 네이버 검색 API | 하루 25,000건 무료 | https://developers.naver.com/apps |
| 연관 검색어 | 네이버 자동완성 | **키 없이 사용** | 자동으로 사용합니다 |

- **AI 키가 없어도** 내장 글 틀로 1500자 이상 글을 만듭니다. 다만 주제에 맞는 구체적인 내용은 Gemini 키를 넣었을 때 훨씬 좋아집니다.
- **이미지 키가 없어도** Openverse(CC 라이선스)와 Picsum 으로 사진을 받아 정사각형·고화질로 다듬습니다. Pixabay 키를 넣으면 한국어 키워드로 주제에 맞는 사진을 찾습니다.

## 6. 폴더 구조

```
글쓰기.bat          실행 파일 (키워드 2~3개, 제목 입력)
main.js             Electron 메인 (화면과 자동화 연결)
preload.cjs         화면에 기능을 열어 주는 다리
renderer/           프로그램 화면 (입력, 미리보기, 진행 기록)
  imagelab.js       이미지 정사각형 자르기·선명도·밝고 화사하게 보정·썸네일 글씨
src/
  research.js       키워드별 연관 검색어 조사
  content.js        글 작성 (AI 지시문 + 내장 글 틀)
  gemini.js         무료 AI 호출
  style.js          합니다체 교정, 조사 교정
  images.js         무료 이미지 검색과 내려받기
  topics.js         연관 검색어 의도 분류 + 의도별 문단 + 사진 검색어 사전
  blocks.js         에디터에 넣을 블록 변환 (크기, 색, 굵게, 구분선)
  naver.js          브라우저 자동화 (키스트로크 입력 + 임시저장)
data/
  images/           만들어진 이미지
  drafts/           글 초안 (json, txt, html)
  naver-profile/    네이버 로그인 정보
```

## 7. 자주 생기는 문제

| 증상 | 해결 방법 |
| --- | --- |
| 로그인 화면에서 멈춤 | 열린 브라우저에서 직접 로그인합니다. 5분까지 기다립니다. |
| 글자 크기나 색이 안 들어감 | 네이버가 도구 모음을 바꾼 경우입니다. **빠른 입력(붙여넣기)** 방식으로 바꿔 보시기 바랍니다. |
| 글쓰기 화면이 안 열림 | `.env` 의 `NAVER_BLOG_ID` 에 블로그 아이디(blog.naver.com/**아이디**)를 적어 주시기 바랍니다. |
| 임시저장 버튼을 못 찾음 | 글은 모두 입력된 상태이므로 브라우저에서 저장 버튼을 직접 누르면 됩니다. |
| 이미지가 주제와 안 맞음 | Pixabay 키를 넣으면 한국어 키워드로 찾습니다. Gemini 키가 있으면 소제목에 맞는 영어 검색어를 자동으로 만듭니다. |
| 입력이 너무 빠름 또는 느림 | `.env` 의 `TYPE_DELAY` 값을 조절합니다. (기본 8, 숫자가 클수록 느립니다) |
